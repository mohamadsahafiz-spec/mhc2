# Architecture Review Template

## Purpose

This template provides a structured framework for evaluating software architecture before, during, or after implementation.

The objective is to ensure that architectural decisions remain aligned with Engineering-OS principles, reduce long-term engineering cost, and support sustainable system evolution.
